# Test Directory

This directory contains all tests for the Trackwise application following clean architecture principles.

## Directory Structure

```
test/
├── helpers/           # Test helpers and mock generators
│   ├── test_helpers.dart        # Common test utilities and mock annotations
│   └── test_helpers.mocks.dart  # Generated mocks (auto-generated by build_runner)
├── fixtures/          # Test data fixtures
│   └── test_fixtures.dart       # Sample data matching Firestore schema
├── core/              # Tests for core utilities
│   ├── error/
│   │   └── failures_test.dart   # Tests for Failure classes
│   └── utils/
│       └── validators_test.dart # Tests for input validators
└── widget_test.dart   # Placeholder widget test
```

## Running Tests

### Run all tests
```bash
flutter test
```

### Run specific test file
```bash
flutter test test/core/utils/validators_test.dart
```

### Run with coverage
```bash
flutter test --coverage
```

Coverage reports are generated in `coverage/lcov.info`.

### Generate coverage HTML report (requires lcov)
```bash
genhtml coverage/lcov.info -o coverage/html
open coverage/html/index.html
```

## Writing Tests

### Unit Tests

Unit tests follow the Arrange-Act-Assert pattern:

```dart
test('should return null for valid item name', () {
  // arrange
  const validName = 'Test Item';

  // act
  final result = Validators.validateItemName(validName);

  // assert
  expect(result, null);
});
```

### Using Mocks

Mocks are generated using Mockito. To generate mocks:

1. Add `@GenerateMocks([ClassName])` annotation in `test/helpers/test_helpers.dart`
2. Run `flutter pub run build_runner build --delete-conflicting-outputs`
3. Use generated mocks in tests:

```dart
import 'package:mockito/mockito.dart';
import '../helpers/test_helpers.mocks.dart';

void main() {
  late MockFirebaseFirestore mockFirestore;

  setUp(() {
    mockFirestore = MockFirebaseFirestore();
  });

  test('example test with mock', () {
    // Stub mock behavior
    when(mockFirestore.collection('Item')).thenReturn(mockCollection);

    // ... test code
  });
}
```

### Test Fixtures

Use fixtures from `test/fixtures/test_fixtures.dart` for consistent test data:

```dart
import '../../fixtures/test_fixtures.dart';

test('example with fixtures', () {
  final itemData = createTestItemData(itemName: 'Custom Name');
  // ... test code
});
```

## Test Organization

Tests are organized by layer and feature:

- **`core/`** - Tests for core utilities, errors, and base classes
- **`features/[feature_name]/domain/`** - Tests for entities and use cases
- **`features/[feature_name]/data/`** - Tests for repositories and data sources
- **`features/[feature_name]/presentation/`** - Tests for BLoCs and widgets
