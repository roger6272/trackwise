# Task: App - Implement BLE commands (handshake, override, sync_complete)

## Description

Implement the new BLE service methods for multi-device protocol: sendHandshake, sendOverrideChunked, and sendSyncComplete. Also create the SyncStatus enum and HandshakeResult model.

## Acceptance Criteria

- [ ] SyncStatus enum: inSync, conflict, wrongAccount
- [ ] HandshakeResult model with status, deviceInstanceId, deviceSyncSeq
- [ ] sendHandshake() - sends handshake, parses 3 response types
- [ ] sendOverrideChunked() - chunks items, sends start/chunks/end
- [ ] sendSyncComplete() - sends sync_complete, returns acknowledgment
- [ ] All commands have 10-second timeout
- [ ] OverrideResult model for override response
- [ ] SyncCompleteResult model for sync_complete response
- [ ] BLE error during chunk send aborts override (no partial state)

## Technical Details

### Data Models
```dart
enum SyncStatus { inSync, conflict, wrongAccount }

class HandshakeResult {
  final SyncStatus status;
  final String deviceInstanceId;
  final int? deviceSyncSeq;  // Only present if conflict
}

class OverrideResult {
  final String status;  // 'override_complete' or 'error'
  final String? message;
}
```

### BLE Methods
```dart
Future<HandshakeResult> sendHandshake({required String uid, required int syncSeq});
Future<OverrideResult> sendOverrideChunked({required int syncSeq, required int selectedId, required List<Item> items});
Future<SyncCompleteResult> sendSyncComplete(int syncSeq);
```

### Chunking Logic
- Chunk size: 10 items per chunk
- Send override_start with total_chunks
- Send each chunk sequentially
- Send override_end with selected_id
