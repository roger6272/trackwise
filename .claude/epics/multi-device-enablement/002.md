# Task: Firmware - NVS storage, device instance ID, and pairing mode

## Description

Implement the core multi-device firmware infrastructure: NVS storage schema for pairing data, device instance ID generation, pairing mode detection, and updated factory reset functionality.

## Acceptance Criteria

- [ ] NVS storage schema implemented (paired_uid, device_instance_id, sync_seq_no)
- [ ] Device instance ID generated on first boot (UUID format)
- [ ] Pairing mode detection on startup (check if paired_uid is empty)
- [ ] Welcome screen displayed when unpaired
- [ ] Factory reset clears pairing, regenerates device_instance_id, clears items
- [ ] Factory reset clears BLE bonding table

## Technical Details

### NVS Keys
```cpp
"paired_uid"          // String: Firebase uid (empty = unpaired)
"device_instance_id"  // String: Unique device identifier (UUID)
"sync_seq_no"         // int32: Last sync sequence number (default: 0)
```

### Device Instance ID
- Generate UUID on first boot
- Regenerate on factory reset
- Persist across normal reboots

### Pairing Mode
- Check paired_uid on setup()
- If empty: enterPairingMode(), displayWelcomeScreen()
- If set: enterNormalMode()

### Factory Reset
- Trigger: Press 'F' key (current firmware)
- Confirm: Display "FACTORY RESET? F=CONFIRM"
- Actions: Clear NVS keys, regenerate ID, clear 100 item slots, clear BLE bonding
