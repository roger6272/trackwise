# Task: App - Update Firestore schema and user repository

## Description

Add new fields to Firestore user document schema and implement repository methods for multi-device support: sync_sequence_no, last_selected_device_item_id, and paired_devices array.

## Acceptance Criteria

- [ ] Firestore schema updated with new fields
- [ ] User entity/model updated with new fields
- [ ] fetchSyncSequenceFromServer() method - always fetches fresh from server
- [ ] updateSyncState() method - updates sync_seq and last_selected_device_item_id
- [ ] addPairedDevice() method - adds device to paired_devices array
- [ ] removePairedDevice() method - removes device from array
- [ ] updateDeviceName() method - renames device in paired_devices array
- [ ] PairedDevice entity created (deviceInstanceId, deviceName, pairedAt)
- [ ] Device limit check (max 10)

## Technical Details

### Firestore Schema
```
users/{uid}:
  // Existing fields...
  sync_sequence_no: int (default: 0)
  last_selected_device_item_id: int (default: -1)
  paired_devices: [
    {
      device_instance_id: String,
      device_name: String,
      paired_at: Timestamp
    }
  ]
```

```dart

```
