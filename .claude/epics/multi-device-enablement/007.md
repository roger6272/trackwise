# Task: App - Implement sync flows with internet check and retry logic

## Description

Implement the complete sync flow logic: performSync (handshake flow), _performNormalSync, and performOverride. Include internet connectivity checks and Firestore retry logic (3 attempts with backoff).

## Acceptance Criteria

- [ ] performSync() - checks internet, sends handshake, handles responses
- [ ] _performNormalSync() - requests prefs, sends sync_complete, updates Firestore
- [ ] performOverride() - checks internet, sends chunked override, updates Firestore
- [ ] Internet connectivity check before sync/override
- [ ] Firestore retry logic (3 attempts with exponential backoff)
- [ ] wrongAccount check before adding to paired_devices
- [ ] Device limit check (max 10 devices)
- [ ] Item limit check (max 100 items) with TooManyItemsFailure
- [ ] Disconnect handling (discard partial data, restart cleanly on reconnect)
- [ ] Proper error handling with failure types

## Technical Details

### Sync Flow
```dart
Future<Either<Failure, SyncResult>> performSync() async {
  // 1. Check internet
  // 2. Fetch FRESH sync_seq from Firestore
  // 3. Send handshake
  // 4. Handle wrongAccount (return error)
  // 5. Add to paired_devices if new (check limit)
  // 6. If in_sync → _performNormalSync()
  // 7. If conflict → return SyncConflictFailure for UI
}
```

### Retry Logic
```dart
// Retry up to 3 times with backoff
for (var attempt = 1; attempt <= 3; attempt++) {
  try {
    await firestoreOperation();
    return success;
  } catch (_) {
    if (attempt == 3) return failure;
    await Future.delayed(Duration(seconds: attempt));
  }
}
```

### Failure Types
- NoInternetFailure
- WrongAccountFailure
- DeviceLimitFailure
- SyncConflictFailure (with deviceSyncSeq, appSyncSeq)
- SyncFailure (generic)
- FirestoreUpdateFailure
- TooManyItemsFailure (>100 items)

### Disconnect Handling
- Normal sync: Discard partial data, don't update Firestore. On reconnect, handshake succeeds again.
- Override: Device may have partial data but sync_seq NOT updated. On reconnect, conflict detected again, override restarts.
