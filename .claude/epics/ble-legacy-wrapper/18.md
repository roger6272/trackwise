# Task 3: Test with Device and Delete Old Files

## Objective

Verify BLE functionality works with real ESP32 device, then delete the `custom_code/actions/` directory to complete Phase 3c cleanup.

## Part 1: Device Testing

### Test Checklist

Use the Bluetooth Test Page (`BluetoothTestPage`) to verify:

- [ ] **Permissions** - Bluetooth permissions granted
- [ ] **Scan** - ESP32 device discovered
- [ ] **Connect** - Successfully connects to device
- [ ] **Time Sync** - Time sync command sent
- [ ] **Send Items** - Items sent to device
- [ ] **Request Prefs** - Prefs received, counts updated in Firebase
- [ ] **Request Logs** - Logs received and inserted into Firebase
- [ ] **Pagination** - If device has multiple log pages, all are fetched
- [ ] **Clear Logs** - `clear_logs` command sent after logs fetched
- [ ] **Disconnect** - Clean disconnect

### How to Test

1. Run the app on a physical device (not emulator)
2. Navigate to Bluetooth Test Page
3. Click "Run All Tests" or test individually
4. Check Firebase Console for:
   - Item count updates (prefs sync)
   - New EventLog entries (logs sync)

### If Tests Fail

**Do NOT proceed to Part 2** if any BLE test fails.

Debug steps:
1. Check `debugPrint` output in console
2. Compare behavior with old code (temporarily revert imports)
3. Verify `BleLegacyState` singleton is working
4. Check Firebase rules if writes fail
