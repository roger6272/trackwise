# Task: App: OTA Presentation — Bloc, Update Banner, Progress Sheet, Post-Reboot

## Description
Build the OTA presentation layer: OtaBloc with full state machine (Idle, Available, Required, Downloading, Transferring, Verifying, Rebooting, Complete, Error), update banner widget (dismissable/non-dismissable), progress bottom sheet (download→transfer progress with cancel), post-reboot handling (suppress disconnect, auto-reconnect, version verify), app version gate UI, and offline error handling.

## Acceptance Criteria
- [ ] OtaBloc with states: Idle, Available, Required, Downloading, Transferring, Verifying, Rebooting, Complete, Error
- [ ] Update banner on BluetoothPage device card area — dismissable for optional, non-dismissable for required
- [ ] Tapping banner opens bottom sheet with changelog, version info, "Update Now" button
- [ ] Progress bottom sheet shows sequential download → transfer progress
- [ ] Cancel button with confirmation dialog during transfer
- [ ] "Don't turn off your device" message during transfer
- [ ] Post-reboot: awaitingOtaReboot flag suppresses disconnect error in BluetoothBloc
- [ ] Auto-reconnect within 30s timeout after reboot
- [ ] Full handshake on reconnect, verify new firmwareVersion, show success message
- [ ] 30s timeout: show error "Device didn't respond after update. Try turning it off and on again."
- [ ] App version gate: show "Update the Traxelos app" when min_app_version > current
- [ ] Offline handling: show error if user taps "Update Now" without internet
- [ ] Battery < 20%: show clear message about insufficient battery

## Technical Details
- Files:
