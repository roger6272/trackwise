# Task: Firebase: Storage Structure, Remote Config, Security Rules, Publish Script

## Description
Set up Firebase infrastructure for OTA: Storage structure for firmware binaries and metadata (latest.json), Remote Config for min_firmware_version parameter, security rules for authenticated read-only access, and a publish_firmware.sh script for developer use.

## Acceptance Criteria
- [ ] Firebase Storage structure: firmware/latest.json + firmware/bins/<binary files>
- [ ] latest.json contains: version, file_path, sha256, min_app_version, changelog, released_at
- [ ] Remote Config parameter min_firmware_version created and updatable server-side
- [ ] Security rules: authenticated read-only for firmware files, admin-only upload
- [ ] publish_firmware.sh script auto-generates latest.json with correct SHA256
- [ ] Script validates inputs and provides clear error messages

## Technical Details
- Storage path: gs://<bucket>/firmware/latest.json, gs://<bucket>/firmware/bins/trackwise_X.Y.Z.bin
- latest.json schema: { version: "X.Y.Z", file_path: "firmware/bins/trackwise_X.Y.Z.bin", sha256: "<hex>", min_app_version: "X.Y.Z", changelog: "...", released_at: "ISO8601" }
- Remote Config: min_firmware_version default value, fetchable client-side
- Security rules: allow read if request.auth != null; deny write (admin via console/CLI)
- Publish script: lives in scripts/publish_firmware.sh, computes sha256sum, generates JSON
