# Task: Firmware: Dual-OTA Partition Table + MAX17048 Battery + Battery Service

## Description
Switch ESP32 from single-app to dual-OTA partition layout, add MAX17048 fuel gauge I2C driver for battery SOC reading, and expose battery level as standard BLE Battery Service (0x180F) with Battery Level characteristic (0x2A19) supporting read + notify.

## Acceptance Criteria
- [ ] Dual-OTA partition table configured and device flashed
- [ ] MAX17048 driver reads SOC% from I2C address 0x36, register 0x04
- [ ] Standard Battery Service (0x180F) advertised via BLE
- [ ] Battery Level characteristic (0x2A19) supports read and notify
- [ ] Battery level updates periodically via notify
- [ ] Existing functionality (counting, BLE commands, display) unaffected by partition change

## Technical Details
- Partition table: switch from single-app to dual-OTA layout in `firmware/Trackwise_ESP32/`
- MAX17048: I2C address 0x36, SOC register 0x04 — read percentage as uint8
- Battery Service: use Bluetooth SIG standard service UUID 0x180F
- Battery Level characteristic: UUID 0x2A19, read + notify properties
- One-time USB flash prerequisite for partition table change

## Dependencies
- [ ] MAX17048 IC must be on PCB and wired to I2C bus (hardware prerequisite)
