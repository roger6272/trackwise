# Task: App: Analytics — OTA Telemetry Events + Firmware Version User Property

## Description
Add OTA telemetry events and firmware version tracking to the existing AnalyticsService. Events: ota_started, ota_completed, ota_failed(reason), ota_cancelled. User property: firmware_version set on each device connect for fleet-wide version distribution queries.

## Acceptance Criteria
- [ ] ota_started event logged when OTA transfer begins
- [ ] ota_completed event logged with duration and version info on success
- [ ] ota_failed event logged with failure reason (timeout, hash_mismatch, disconnect, low_battery, etc.)
- [ ] ota_cancelled event logged when user cancels mid-transfer
- [ ] firmware_version user property set on each device connect via setUserProperty
- [ ] All events added to existing AnalyticsService (lib/core/services/analytics_service.dart)
- [ ] No new dependencies (firebase_analytics already exists)

## Technical Details
- Modify existing AnalyticsService in lib/core/services/analytics_service.dart
- Events: logEvent(name: 'ota_started', parameters: {from_version, to_version})
- logEvent(name: 'ota_completed', parameters: {from_version, to_version, duration_seconds})
- logEvent(name: 'ota_failed', parameters: {reason, from_version, to_version})
- logEvent(name: 'ota_cancelled', parameters: {from_version, to_version, progress_percent})
- User property: setUserProperty(name: 'firmware_version', value: version_string)
- Called from OtaBloc state transitions and BluetoothBloc on connect
