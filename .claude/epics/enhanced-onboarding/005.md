# Task: Implement Step 3 (Device Scan and Connect)

## Description
Build the device scan/connect step using extracted BLE widgets and the existing `BluetoothBloc`. Handle permissions inline, Bluetooth-off state, device list, connection progress, and all handshake outcomes. Include skip and "I don't have a device yet" options.

## Acceptance Criteria
- [ ] On step entry: request Bluetooth and location permissions if not granted
- [ ] If Bluetooth off: show "Turn on Bluetooth" prompt
- [ ] If permissions denied: show explanation with "Open Settings" option
- [ ] Once ready: auto-start BLE scan showing discovered Traxelos devices
- [ ] Tap device to connect — show connection progress (scanning → connecting → paired)
- [ ] On connection failure: show retry button and troubleshooting tips
- [ ] On successful connection: execute handshake automatically via `BluetoothBloc`
- [ ] Handle handshake results:
  - `uninitialized`: advance to Step 4
  - `in_sync`: advance to Step 4
  - `wrong_account`: show error with factory reset instructions
  - `conflict`: show conflict resolution dialog
- [ ] "Skip" and "I don't have a device yet" options available — mark onboarding complete, go to home
- [ ] Uses extracted BLE widgets from Task 001 (permission banner, device list tile, scan button)
- [ ] Observes BLE state via `BlocListener<BluetoothBloc>`
- [ ] Uses `AppColors` and `Theme.of(context).textTheme` — no hardcoded styles
- [ ] Proper `Semantics` labels on all interactive elements
- [ ] Touch targets at least 48dp
- [ ] Responsive from 320dp through tablet

## Technical Details
- Uses `BlePermissionBanner`, `BleDeviceListTile`, `BleScanButton` from Task 001
- BLE events: dispatch `StartScan`, `ConnectToDevice` to `BluetoothBloc`
- Listen for `BluetoothState` changes to track connection/handshake progress
- Handshake is automatic after connection — `BluetoothBloc._performInitialSync()` handles it
- Set parent state `_devicePaired = true` on successful handshake
- If device not paired (skip), Step 4 is also skipped — go straight to home
