# Task: Restyle Auth Pages

## Description
Update the clean architecture auth pages (login, signup, forgot password) to match the FlutterFlow auth page designs exactly. Users should not notice any visual difference after the migration.

## Acceptance Criteria
- [ ] Login page matches FF `auth2_login_widget.dart` design exactly
- [ ] Signup page matches FF `auth2_create_widget.dart` design exactly
- [ ] Forgot password page matches FF `auth2_forgot_password_widget.dart` design exactly
- [ ] All form fields have identical styling (borders, colors, spacing)
- [ ] Buttons match FF styling (colors, rounded corners, shadows)
- [ ] Error messages display identically
- [ ] Social login buttons (Google, Apple) match FF design
- [ ] Screenshots show no visual difference

## Technical Details

### Files to Modify
```
lib/features/auth/presentation/pages/
├── login_page.dart
├── signup_page.dart
└── forgot_password_page.dart
```

### FF Reference Files
```
lib/account_profile_creation/
├── auth_2_login/auth2_login_widget.dart
├── auth_2_create/auth2_create_widget.dart
└── auth_2_forgot_password/auth2_forgot_password_widget.dart
```

### Approach
1. Open FF auth page and clean arch page side by side
2. Copy widget structure (Column, Container, padding)
3. Match colors using `AppTheme` or direct color values
4. Match typography using theme text styles
5. Match spacing (EdgeInsets, SizedBox heights)
6. Match form field decorations (InputDecoration)
7. Match button styles (ElevatedButton.styleFrom)

### Key FF Styling to Replicate
- Background gradient or color
- Logo/header section
- Form field appearance (outlined, filled, border radius)
- Button colors and shapes
- Link text styling
- Animation effects (if any)
