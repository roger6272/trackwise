# Task: Firmware snprintf and non-blocking vibration

## Description
Optimize firmware memory usage by using snprintf() for preference key generation, and convert blocking vibration delay to non-blocking timer pattern.

## Acceptance Criteria
- [ ] All preference key strings use snprintf() instead of String concatenation
- [ ] Vibration uses non-blocking timer with millis() check in loop
- [ ] Device compiles and uploads successfully
- [ ] Button presses, vibration, and item selection work correctly
- [ ] No BLE interference during vibration

## Technical Details
- File: firmware/Trackwise_ESP32/Trackwise_ESP32.ino
- Lines 332-341: Replace `("id_" + String(index)).c_str()` with `snprintf(key, sizeof(key), "id_%d", index)`
- Lines 790-795: Replace blocking `delay(300)` with:
  ```cpp
  struct VibrationState { unsigned long endTime = 0; bool isActive = false; } vibration;
  void triggerVibrationNonBlocking(int duration = 300) {
    digitalWrite(VIBRATION_PIN, HIGH);
    vibration.endTime = millis() + duration;
    vibration.isActive = true;
  }
  // In loop(): check and turn off when endTime reached
  ```
