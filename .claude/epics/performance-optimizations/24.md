# Task: Firmware error responses via NOTIFY

## Description
Add explicit error response messages from firmware via NOTIFY characteristic when commands fail, improving debugging capability.

## Acceptance Criteria
- [ ] Firmware sends error JSON via NOTIFY on command failures
- [ ] Error format: {"type":"error","cmd":"<command>","reason":"<reason>"}
- [ ] App handles error messages appropriately
- [ ] Better debugging visibility for command failures

## Technical Details
- File: firmware/Trackwise_ESP32/Trackwise_ESP32.ino (WriteCallback class)
- Add error notification helper:
  ```cpp
  void notifyError(const char* cmd, const char* reason) {
    StaticJsonDocument<256> doc;
    doc["type"] = "error";
    doc["cmd"] = cmd;
    doc["reason"] = reason;
    String jsonOut;
    serializeJson(doc, jsonOut);
    jsonOut += "\n";
    NotifyChar->setValue(jsonOut.c_str());
    NotifyChar->notify();
  }
  ```
- Call notifyError() on JSON parse failures, invalid commands, etc.
- Update app to handle error message type in sync_device_data_usecase.dart
