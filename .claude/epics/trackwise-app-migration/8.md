# Task: Foundation Setup

## Description

Enable the new AppRouter and AppTheme in main.dart, replacing the FlutterFlow navigation and theme system. This is the foundational task that unlocks all subsequent migration work.

## Acceptance Criteria

- [ ] `main.dart` uses `AppRouter.router` instead of FF `createRouter()`
- [ ] `main.dart` uses `AppTheme` instead of `FlutterFlowTheme`
- [ ] Migration flags `useNewRouter` and `useNewTheme` set to `true`
- [ ] App launches successfully with `flutter run`
- [ ] No runtime errors on app startup
- [ ] Basic navigation works (can navigate between placeholder routes)

## Technical Details

### Files to Modify
- `lib/main.dart` - Switch router and theme
- `lib/core/config/migration_flags.dart` - Enable flags
- `lib/core/router/app_router.dart` - Verify all routes defined
- `lib/app.dart` - Update if needed for theme integration

### Implementation Steps
1. Review current `main.dart` to understand FF integration points
2. Update `MigrationFlags.useNewRouter = true`
3. Update `MigrationFlags.useNewTheme = true`
4. Replace router initialization in `main.dart`
5. Replace theme provider in MaterialApp
6. Run app and verify startup
7. Test basic navigation to ensure router works

### Key Considerations
- Keep FF code intact (just bypass it via flags)
- Ensure BLoC providers are still properly injected
- Firebase initialization must remain unchanged
- DI (get_it) setup must work with new router
