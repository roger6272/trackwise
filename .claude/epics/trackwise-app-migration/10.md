# Task: Items Flow & Navigation Bar

## Description

Wire up items pages (list, detail, form) to the router, create the bottom navigation bar widget, and ensure all item CRUD operations work correctly.

## Acceptance Criteria

- [ ] Items list page (main page) shows at `/` or `/home` route
- [ ] Item detail page accessible at `/item/:id` route
- [ ] Item create page accessible at `/item/new` route
- [ ] Item edit page accessible at `/item/:id/edit` route
- [ ] Bottom navigation bar created with 3 tabs (Home, Bluetooth, Profile)
- [ ] Navigation bar highlights active tab
- [ ] Total/Today toggle works on items list
- [ ] Swipe actions work (Activate, Update, Delete)
- [ ] Add item button works (with device connection check)
- [ ] Item CRUD operations sync with Firestore

## Technical Details

### Files to Create
- `lib/core/widgets/app_navigation_bar.dart` - Bottom navigation with 3 tabs

### Files to Modify
- `lib/core/router/app_router.dart` - Add items routes
- `lib/features/items/presentation/pages/items_list_page.dart` - Add nav bar, verify BLoC
- `lib/features/items/presentation/pages/item_detail_page.dart` - Verify routing params
- `lib/features/items/presentation/pages/item_form_page.dart` - Verify create/edit modes

### Navigation Bar Specs (from FF NavigationBarWidget)
- 3 icons: Home (home_rounded), Bluetooth (bluetooth_connected), Profile (person_rounded)
- Rounded container with shadow
- Active tab highlighted with primary color
- Routes: `/home`, `/bluetooth`, `/profile`

### Implementation Steps
1. Create `AppNavigationBar` widget matching FF design
2. Add items routes to `AppRouter`
3. Integrate nav bar into items list page
4. Wire `ItemsBloc` to items list page
5. Implement Total/Today toggle using bloc state
6. Implement swipe actions with slidable
7. Test CRUD operations

### Key Considerations
- Nav bar needs access to current route for highlighting
- Device connection state affects add/activate/update/delete actions
- Items list streams from Firestore in real-time
