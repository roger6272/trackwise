# Traxelos UX Specification

> Generated 2026-02-15 from codebase analysis

## 1. App Overview

Traxelos is a Flutter-based mobile counting and tracking application that pairs with a Traxelos One hardware device via Bluetooth Low Energy. Users create named items (counters), increment them from the physical device or app, organize items into categories, view historical data through charts and cycle periods, and export data via CSV email. The app supports light and dark themes, Firebase authentication (email, Google, Apple), and real-time BLE synchronization.

---

## 2. Navigation Map

### Tab Structure

The app uses a floating bottom navigation bar with three tabs:

| Tab | Icon | Label | Root Route |
|-----|------|-------|------------|
| Home | `home_rounded` | Home | `/` (ItemsListPage) |
| Bluetooth | Dynamic (see below) | Bluetooth | `/bluetooth` (BluetoothPage) |
| Account | `person_rounded` | Account | `/profile` (ProfilePage) |

The Bluetooth tab icon changes dynamically based on connection state:
- Connected: `bluetooth_connected` icon (green tint)
- Connecting: `bluetooth_searching` icon
- Disconnected: `bluetooth` icon (default)

### Route Hierarchy

```
Auth routes (no bottom nav):
  /login ..................... LoginPage
  /signup .................... SignupPage
  /forgot-password ........... ForgotPasswordPage
  /onboarding ................ OnboardingPage

Shell routes (with bottom nav):
  / .......................... ItemsListPage
    /items/form .............. ItemFormPage (create)
    /items/form (with extra).. ItemFormPage (edit)
    /items/:id ............... ItemDetailPage
  /bluetooth ................. BluetoothPage
    /bluetooth/search ........ BluetoothSearchPage
  /profile ................... ProfilePage
    /profile/export .......... ExportPage
    /profile/deleted-items ... DeletedItemsPage
    /profile/edit ............ EditProfilePage
    /profile/help ............ HelpSupportPage
    /profile/categories ...... ManageCategoriesPage
    /profile/paired-devices .. PairedDevicesPage
```

### Auth Redirect Logic
- Unauthenticated users are redirected to `/login`
- Authenticated users who need onboarding are redirected to `/onboarding`

| **Purpose** | Authenticate an existing user |

### 3.4 OnboardingPage

| Section | Detail |
|---------|--------|
| **Route** | `/onboarding` |
| **Purpose** | Welcome new users, collect profile info, and optionally pair a device |
| **Entry points** | Automatic redirect after signup or for users who haven't completed onboarding |

**Layout**
- Full-screen PageView with 4 steps
- Progress dots at the top indicating current step
- Back button (visible on steps 2-3 only)

**Step 1 — Profile Setup**
- "Tell us about yourself" heading with subtitle "Help us personalise your experience."
- Display name text field (hint: "Your name (optional)")
- "What will you use Traxelos for?" — 5 radio card options:
  - Inventory Tracking — "Track stock, supplies, or materials"
  - Habit Tracking — "Build and maintain daily habits"
  - Fitness & Exercise — "Count reps, sets, or workouts"
  - Manufacturing — "Track production or quality counts"
  - Other — "Something else"
- "How did you hear about us?" (labeled "Optional") — 5 selectable chip options:
  - Friend or Colleague
  - Social Media
  - Search Engine
  - App Store
  - Other
- "Continue" button
- "Skip for now" link

**Step 2 — Welcome Intro**
- Device hero icon at top
- "Welcome to Traxelos One" heading
- Three info sections with icons:
  - "How it works" — "A physical counting device that pairs with this app via Bluetooth to track anything you need."
  - "What you need" — "Your Traxelos One device nearby with Bluetooth enabled on your phone."
  - "What's next" — "We'll help you pair your device so you can start counting right away."
- "Continue" button

**Step 3 — Device Setup**
- "Find Your Device" heading with subtitle "Make sure your Traxelos One is powered on and nearby"
- "Scan for Devices" button (auto-starts on entry when permissions are granted)
- Device list (sorted by signal strength)
- "I don't have a device yet" link (skips to finish)

**Step 4 — Done**
- Success illustration/icon
- "You're all set!" heading
- Shows paired device name if connected
- "Get Started" button (navigates to home `/`)

**Interactive Elements**

| Element | Action |
|---------|--------|
| Progress dots | Visual indicator only (not tappable) |
| Back button (steps 2-3) | Returns to previous step |
| Name field (step 1) | Text input for display name |
| Use case radio cards (step 1) | Single selection from 5 options |
| Referral chips (step 1) | Single selection from 5 options |
| "Continue" button | Advances to next step |
| "Skip for now" link (step 1) / "I don't have a device yet" link (step 3) | Advances without completing; step 3 skip finishes onboarding |
| "Get Started" button (step 4) | Navigates to home page |

**States (Step 3 — Device Setup)**
- Permissions required: Prompt to grant Bluetooth permissions
- Bluetooth disabled: Prompt to enable Bluetooth
- Scanning: Shows spinner, lists discovered devices
- Connecting: Shows connecting indicator for selected device
- Syncing: Shows sync progress after successful connection
- Connected: Shows success, transitions to step 4

### 3.5 ItemsListPage (Home)

| Section | Detail |
|---------|--------|
| **Route** | `/` |
| **Purpose** | View, search, filter, and manage all tracking items |
| **Entry points** | Home tab in bottom navigation |

**Layout**
- App bar: "Items" title (centered), search icon button, add item icon button (circular, primary colored)
- Category filter dropdown (shown when categories exist)
- Search field (shown when search activated)
- Active item chip (shown when connected with a pinned item)
- Connection status banner (disconnected or syncing)
- Today/Total toggle divider
- Items list (grouped by category in "All" view, or flat in single-category view)

**Interactive Elements**

| Element | Action |
|---------|--------|
| Search icon (app bar) | Opens search field below app bar |
| Add item button (app bar) | Opens ItemFormPage in create mode; requires device connection; shows limit dialog at 100 items |
| Category dropdown | Filters items by category. Options: "All Categories", each user category, "Uncategorized", "Manage Categories" (navigates to ManageCategoriesPage) |
| Search field | Debounced (300ms) text search filtering items by name. X button clears text or closes search |
| Active item chip | Shows pinned item name and category; tapping navigates to that item's category filter |
| "Tap to connect device" banner | Tappable; navigates to Bluetooth tab |
| Today/Total toggle | Tap to switch between showing today's count vs total count for all items |
| Item tile (tap) | Navigates to ItemDetailPage for that item |
| Item tile (long press + drag) | Reorders item within its category (connected only) |
| Item tile (slide left) | Reveals 3 action buttons (see Slidable Actions below) |
| Category label headers | Non-interactive section headers in "All" view |

**Slidable Actions (left-to-right when swiped)**

| Action | Icon | Color | Behavior |
|--------|------|-------|----------|
| Activate (Pin) | `push_pin_rounded` | Purple | Pins this item as active on device; sends category items to device |
| Edit | `edit` | Primary | Opens ItemFormPage in edit mode |
| Delete | `delete_outline_rounded` | Red | Shows confirmation dialog, then soft-deletes item |

All slidable actions show as disabled (gray) when device is disconnected and show a "Please connect your device first" dialog instead.

**States**
- Loading: Centered circular progress indicator
- Empty (no items): Centered inbox icon, "No items yet" heading, "Create your first item to start tracking" subtitle, "Create Item" button (disabled when disconnected, with "Connect device to create items" hint)
- Populated: Scrollable list of item tiles grouped by category
- No search results: Search-off icon, "No items found", "Try a different search term"
- Disconnected: Items list shown at 50% opacity; connection banner visible; slidable actions disabled

**Dialogs**

| Dialog | Trigger | Content | Actions |
|--------|---------|---------|---------|
| Connect Device Required | Tapping add/slidable when disconnected | "Please connect your device first" | "Ok" |
| Item Limit Reached | Tapping add when 100 items exist | "You can only create up to 100 items..." | "Ok" |
| Delete Confirmation | Delete slidable action | "Are you sure you want to delete '[name]'?" | "Cancel", "Delete" (red) |

**One-Time Hints**
- Activation hint: Tooltip overlay shown when connected but no item is pinned; explains the pin/activate feature
- Reorder hint: Tooltip overlay with lift animation on first item; explains long-press drag to reorder

### 3.7 ItemFormPage

| Section | Detail |
|---------|--------|
| **Route** | `/items/form` |
| **Purpose** | Create a new tracking item or edit an existing one |
| **Entry points** | Add button on ItemsListPage (create); Edit slidable action on ItemsListPage (edit) |

**Layout**
- App bar: "Create Item" or "Edit Item" title with back button
- Scrollable form with fields:
  - Item Name (text field)
  - Category (dropdown)
  - Initial Value (number field, create mode only)
  - Goal (optional number field)
  - Count Per Press (number field)
  - Reminder section: Type dropdown, Value field (conditional)
- Bottom button row: "Cancel" and "Create"/"Update"

**Interactive Elements**

| Element | Action |
|---------|--------|
| Back button | Returns to previous screen without saving |
| Item Name field | Text input, max 30 characters, required |
| Category dropdown | Selects a category; includes "Manage Categories" option that navigates to ManageCategoriesPage |
| Initial Value field | Number input (0 to max int), create mode only |
| Goal field | Optional number input (0 to max int) |
| Count Per Press field | Number input (1 to 1000), required |
| Reminder Type dropdown | Options: "None", "At Target", "Every X" |
| Reminder Value field | Number input (0 to 9999), shown when reminder type is not "None" |
| "Cancel" button | Discards changes, returns to previous screen |
| "Create" / "Update" button | Validates and saves; syncs with device |

**Validation**
- Item Name: Required, max 30 characters, no duplicate names (checked against active and deleted items)
- Initial Value: Must be >= 0 (create mode only)
- Goal: Optional; if provided, must be >= 0
- Count Per Press: Required, range 1-1000
- Reminder Value: Range 0-9999

**States**
- Create mode: Empty form, "Create Item" title, Initial Value field visible
- Edit mode: Pre-filled form, "Edit Item" title, Initial Value field hidden
- Submitting: Button shows loading indicator
- Validation error: Red text below invalid fields

## 4. Shared Components

### 4.1 Bottom Navigation Bar (AppShell)

- Floating bar with rounded corners and shadow at the bottom of the screen
- 3 tabs: Home, Bluetooth, Account
- Bluetooth tab icon is dynamic (changes with connection state — see Navigation Map)
- Includes a MultiBlocListener for auto-reconnect SnackBars:
  - On unexpected disconnect: "Device disconnected" SnackBar
  - On successful auto-reconnect: "[Device name] reconnected" SnackBar

### 4.2 BleDeviceListTile

- Used on: BluetoothSearchPage
- Card with leading signal strength icon, device name (or "Unknown Device"), device ID, signal strength in dBm
- Signal icon color indicates strength: green (excellent, > -50 dBm), yellow (good, > -70 dBm), red (weak)
- Trailing: chevron arrow normally; spinner when connecting
- Disabled (non-tappable) when connecting

### 4.3 BleStatusBanner

- Used on: BluetoothSearchPage
- Full-width colored banner with text message and optional action widget
- Used for permission warnings and Bluetooth disabled notifications

### 4.4 SyncConflictDialog

- Used on: BluetoothPage (triggered by sync sequence mismatch)
- Title: "Sync Required"
- Body: "Your device '[name]' needs to be updated to match your app." with device ID in monospace
- Warning: "Any counts on this device since your last sync will be replaced."
- Actions: "Cancel" (disconnects), "Sync Now" (triggers app-to-device override)
- Non-dismissible (barrierDismissible: false)

### 4.5 DeviceSetupDialog

- Used on: During BLE connection when an uninitialized device is detected
- Title: "New Device Detected"
- Body: "This will pair the device to your account. Your items will sync automatically."
- Actions: "Cancel" (disconnects), "Set Up" (pairs and syncs)
- Non-dismissible

### 4.6 WrongAccountDialog

- Used on: During BLE connection when device is locked to a different user
- Title: "Wrong Account"
- Body: "This device is paired to a different account." with instructions to sign in with the original account or factory reset
- Actions: "OK" (dismisses and disconnects)
- Non-dismissible

### 4.7 CategoryFormDialog

- Used on: ManageCategoriesPage
- AlertDialog with a single text field for category name
- Title: "New Category" (create) or "Edit Category" (edit)
- Field: Category name with max length counter (max 30 characters)
- Hint text: "e.g., Electronics, Office Supplies"
- Validation: Name is required (cannot be empty)
- Actions: "Cancel", "Create" (create mode) or "Save" (edit mode)

### 4.8 CycleSelectionBottomSheet

- Used on: ItemDetailPage
- Bottom sheet with drag handle, "Select Cycle" header, close button
- Scrollable list of cycle rows:
  - Individual cycles first (current cycle on top with green dot)
  - "All Time" row at bottom with infinity icon
- Each cycle row shows: radio indicator, cycle name, subtitle (cycle number, date range, press count), edit (rename) icon
- Rename inline: Tapping edit icon converts label to a text field (max 20 chars) with checkmark button
- Tapping a row selects it and closes the sheet

### 4.9 StaticHeader (Item Detail)

- Used on: ItemDetailPage
- Card containing:
  - Count ring: Circular progress painter with count centered
    - With goal (current cycle): Colored ring showing progress, success color when complete
    - Without goal: Gray ring outline
    - Historical/All Time: Gray ring with cycle total
  - Goal badge: Pill showing "X% - Y to goal" or "X/Y - Complete!"
  - Date info: "Started [date]" (current) or "[date] -> [date] - X days" (historical)
  - Config stats row: "Per Press: +N" | "Reminder: [type]" (with icons)

### 4.10 Item Tile (ItemsListPage)

- Used on: ItemsListPage
- Rounded rectangle tile with:
  - Item name (left)
  - Accent bar + count (right, fixed-width for alignment)
  - Chevron arrow (far right)

### 4.11 Social Sign-In Button

- Used on: LoginPage, SignupPage

| Style Name | Usage |
|------------|-------|

| Headline Small | Empty state headings |
| Title Large | Page titles in app bars |
| Title Medium | Item names in tiles, section headings |
| Title Small | Config stat values in item detail |

### Dark/Light Mode

- Toggle via ProfilePage "Dark Mode" switch; persists via SharedPreferences
- Light mode: Light gray scaffold background, white cards
- Dark mode: Near-black scaffold background, dark gray cards
- All colors adapt via `AppColors` helper methods that accept brightness parameter
- Gradient backgrounds on auth screens use the same primary/tertiary colors in both modes
